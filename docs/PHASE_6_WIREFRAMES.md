## 1. WIREFRAME ГЛАВНОЙ — порядок блоков

Предварительная логика из задания проанализирована; порядок уточнён (перестановка: Craftsmanship раньше изделий — сначала понимание «кто и как», потом восхищение; Categories после избранных — от объекта к выбору; Trust перед финальным CTA — подтверждение перед обращением):

| # | Блок | Этап пути | Цель блока |
|---|---|---|---|
| 1 | HERO | DISCOVER | остановить, передать масштаб природы и материала |
| 2 | Материал / Алтайский кедр | UNDERSTAND | что за материал, почему он ценен (только VERIFIED) |
| 3 | Craftsmanship / Производство | UNDERSTAND → TRUST | ручная работа, подтверждённый процесс |
| 4 | Избранные изделия | ADMIRE | показать объекты крупно, вызвать восхищение |
| 5 | Категории каталога | EXPLORE | предложить путь «смотреть всё» по категориям |
| 6 | Featured object / editorial блок | DESIRE | один объект с историей — «хочу такой» |
| 7 | Trust / факты | TRUST | адрес, процесс, единичные экземпляры, контакты |
| 8 | CTA / заявка | CONTACT | заявка ≤ 2 кликов |
| 9 | Footer | — | навигация, контакты |

### Блок 1 — HERO
- Цель: DISCOVER. Контент: фото full-bleed + слоган «Мебель, рождённая природой» (рабочий) + 1 строка подзаголовка + 1 CTA.
- Иерархия: фото 100% viewport → слоган (Display 72–96) → подзаголовок (Body) → CTA текстовая со стрелкой.
- Фото: тайга/горы (VERIFIED-ассет) — PHOTO TO SELECT из библиотеки.
- Переход: CTA → /catalog; скролл → блок 2.

### Блок 2 — Материал / Алтайский кедр
- Цель: UNDERSTAND. Layout: асимметрия 5:7 — слева макро-фото фактуры (full-height блока), справа текст.
- Контент: H2 «Алтайский кедр» + 2–3 абзаца (цельный слэб, живой край, термомодификация — только подтверждённые факты) + макро-детали (2–3 мини-кадра фактуры) + ссылка «Как мы работаем →» (/production).
- Фото: макро фактуры кедра — PHOTO TO SELECT (макро-кадры из папок изделий) / TO PRODUCE (если нет чистой фактуры).

### Блок 3 — Craftsmanship / Производство
- Цель: UNDERSTAND→TRUST. Layout: тёмная full-bleed секция (—dark-bg), 3 модульных блока процесса в ряд (desktop) / стопка (mobile).
- Контент: сушка 60°C 2 мес → термообработка 180–240°C, 8 дней → покрытие POLISTUC (все VERIFIED) + 1 фото процесса/мастерской — PHOTO TO SELECT/TO PRODUCE.
- Переход: ссылка → /production.

### Блок 4 — Избранные изделия
- Цель: ADMIRE. Layout: 3 editorial-карточки (по одной из каждой категории) на бумажном фоне, щедрые отступы (96 px+).
- Карточка: фото 4:5 → название → ID → размеры → цена → «Смотреть →».
- Состав: NEEDS CONFIRMATION (S7). Фото: PHOTO TO SELECT (главные фото).

### Блок 5 — Категории каталога
- Цель: EXPLORE. Layout: 3 плитки в ряд (7 / 19 / 7 изделий) с характерным фото, названием, числом изделий и диапазоном цен.
- Переход: плитка → категория. Диапазоны VERIFIED (8 500–15 000 / 28 000–120 000 / 65 000–190 000 ₽).

### Блок 6 — Featured object / editorial
- Цель: DESIRE. Layout: большой editorial-разворот — фото изделия на 60–70% ширины (асимметрия), рядом история объекта: ID, размеры, 2–3 предложения, цена, CTA «Оставить заявку на это изделие».
- Объект: 1 эксклюзивный стол — PHOTO TO SELECT. История: только VERIFIED-факты.

### Блок 7 — Trust / факты
- Цель: TRUST. Layout: 3–4 коротких факта в ряд: «Новосибирск, Коммунистическая 35» · «Каждое изделие — единственный экземпляр» · «Влажность древесины 3–6%» · «altaywoodslab@gmail.com».
- Без выдуманных гарантий/сертификатов (NON-GOALS).

### Блок 8 — CTA / заявка
- Цель: CONTACT. Layout: centered, много воздуха: H2 «Обсудим ваш стол?» (рабочий вариант) + форма (имя, телефон/e-mail, сообщение) + Primary CTA «Оставить заявку».
- Форма дублирует /contacts; отправка — без backend на этой фазе (mailto/заглушка, решение PHASE 8).

### Блок 9 — Footer
- Тёмный (—primary): навигация (Главная/Каталог/О производстве/Контакты), e-mail, адрес. Высота компактная.

## 2. HERO — два варианта wireframe

### Вариант A — EDITORIAL / ARCHITECTURAL
```
┌────────────────────────────────────────────┐
│ [logo]   Главная Каталог О производстве Контакты   [Оставить заявку] │  ← header, прозрачный
│                                            │
│        ТАЙГА / ГОРЫ  full-bleed 100vh      │
│      (тёмный скрайм снизу 25–35%)          │
│                                            │
│   Мебель,                    ← Display 72–96, │
│   рождённая природой           Cormorant, левая│
│   Столы из цельных слэбов      треть по сетке  │
│   алтайского кедра, ручная     ← Body, muted   │
│   работа                                       │
│   Смотреть коллекцию →        ← text-link CTA  │
└────────────────────────────────────────────┘
```
- Image position: full-bleed, 100vh. Whitespace: внутри фото — по нижней трети; вокруг текста — воздух слева.
- Hierarchy: фото → слоган → подзаголовок → CTA. Navigation: прозрачный header поверх.
- Mobile: вертикальный кроп фото (4:5), слоган 40–52 px по нижней трети, CTA sticky внизу.

### Вариант B — EDITORIAL + TACTILE
```
┌────────────────────────────────────────────┐
│ [logo]   Главная Каталог О производстве Контакты   [Оставить заявку] │
│                                            │
│   ┌──────────────────────┐                 │
│   │                      │   Мебель,        │
│   │  ФОТО ИЗДЕЛИЯ         │   рождённая      │
│   │  (эксклюзивный стол,  │   природой       │
│   │  7:10, full-height)   │                  │
│   │                      │   Цельный слэб   │
│   └──────────────────────┘   алтайского     │
│    ▓ макро-вставка           кедра. Живой   │
│      фактуры (2:3)           край, руки      │
│                              мастера.        │
│                              [Смотреть →]    │
└────────────────────────────────────────────┘
```
- Image position: крупное фото реального изделия (не тайга) + тактильная макро-вставка фактуры — кедр ощутим уже в первом экране.
- Headline справа на бумажном фоне; whitespace — весь правый столбец.
- CTA: стрелочная ссылка (restrained). Hierarchy: фото объекта → слоган → фактура → текст → CTA.
- Mobile: фото сверху (4:5), слоган и текст под ним, макро-вставка горизонтальной лентой, sticky CTA.

Оба варианта применимы; рекомендация — **B для главной** (выполняет решение «кедр — герой» и «одна сильная фотография реального изделия»), A зарезервирован как альтернатива для A/B-теста в PHASE 11. NEEDS CONFIRMATION (визуальный выбор после отбора фото).

## 3. КАТАЛОГ → КАТЕГОРИЯ → ИЗДЕЛИЕ

### /catalog
- Header стандартный. H1 «Каталог» (Cormorant 48–64) + подзаголовок-строка.
- 3 category-плитки в ряд: фото 4:5 → название категории (H2) → «N изделий» (caption) → диапазон цен (Body) → hover: фото scale 1.02, название → accent.
- Мобиль: вертикальный список плиток.

### /catalog/<категория>
- Breadcrumbs: Каталог / Журнальные столы.
- H1 категории + короткое описание (1 строка, рабочий текст) + число изделий.
- Сетка изделий: desktop 3 колонки (19 изделий → 7 рядов), editorial-ритм: карточки строго по сетке, gutters 32, ритм строк 96. НЕ marketplace: без рамок-«полок», без бейджей, без hover-панелей.
- Карточка изделия (обязательный состав):
```
┌──────────────┐
│   ФОТО 4:5   │  ← IMAGE (главное фото, PHOTO TO SELECT)
│              │
├──────────────┤
│ Журнальный   │  ← NAME (рабочее: по ID)
│ стол S002    │
│ S002 · Журн. │  ← PRODUCT ID + категория (caption, muted)
│ 800×500×48   │  ← SIZE (Body)
│ 11 000 ₽     │  ← PRICE (Inter 500)
│ Смотреть →   │  ← CTA (text-link)
└──────────────┘
```
- Дополнительные данные — только VERIFIED; UNKNOWN-поля отсутствуют.
- Переходы: карточка → PDP; breadcrumbs → /catalog; prev/next не нужны на уровне категории.

### Переходы каталога
catalog → категория (клик по плитке) → PDP (клик по карточке) → заявка. Возврат: breadcrumbs на каждом уровне.

## 5. CTA / CONVERSION FLOW

```
LANDING (главная) → PRODUCT DISCOVERY (catalog/категория) → PRODUCT (PDP) → INQUIRY (заявка)
```

Расположение CTA:
| Уровень | Элемент | Тип |
|---|---|---|
| Header (все страницы) | «Оставить заявку» | Primary, постоянный |
| Hero (главная) | «Смотреть коллекцию →» / «Смотреть →» | Text-link |
| Избранные/featured (главная) | «Смотреть →» / «Оставить заявку на это изделие» | Text-link / Inquiry |
| Product cards | «Смотреть →» | Text-link (карточка кликабельна целиком) |

## 9. INTERACTION (каждый эффект — с UX-причиной)

| Эффект | Где | UX-причина |
|---|---|---|
| Header: прозрачный → —bg + border | скролл | читаемость меню поверх контента |
| Section fade (200–400 мс) | появление блоков | мягкое ведение взгляда без отвлечения |
| Slow image reveal (600–900 мс, scale 1.03→1) | hero, PDP | «проявление» объекта, editorial-ощущение |
| Hover: фото scale 1.02, название → accent | карточки, плитки категорий | отклик интерактивности без шума |
| Gallery: свайп + счётчик, стрелки ‹ › | PDP | навигация по фото без перезагрузки |
| Prev/next изделие | PDP | переходы внутри категории (сценарий C) |
| Mobile menu: полноэкранный overlay | ≤767 px | читаемость на малом экране, фокус на навигации |
| Sticky CTA-bar | mobile PDP/контакты | заявка всегда в зоне большого пальца |
| Typography reveal (1 раз, 400–600 мс) | слоган hero | editorial-акцент, один раз — не надоедает |
| Page fade (200 мс) | переходы страниц | связность многостраничной структуры |

Всё отключается по prefers-reduced-motion. Motion ради эффекта не добавлен.

## 10. WIREFRAME QUALITY CONTROL

Критерии: PREMIUM ✅ AUTHENTIC ✅ NATURAL ✅ EDITORIAL ✅ ARCHITECTURAL ✅ TACTILE ✅ RESTRAINED ✅ CONVERSION ✅.

Проверки:
- Похож ли на обычный мебельный магазин? Нет: нет корзины/бейджей/цен «от»/фильтров; карточки editorial. ✅
- Перегружен интерфейс? Нет: 4 пункта меню, один header-CTA, 1 px borders. ✅
- Слишком много текста? Контролируется: блоки 2–3 абзаца, story 2–3 предложения; проверить после наполнения реальными текстами. ⚠️ следить в PHASE 9.
- Крупно ли изделия? Да: hero-PDP ~60% viewport, карточки 4:5 на 3 колонки. ✅
- Считывается ли материал? Да: макро-слой B в hero, материал, featured. ✅
- Понятно ли, что делать? Да: один primary путь «Смотреть → карточка → заявка» + постоянный header-CTA. ✅
- Доверия достаточно? Частично: факты и процесс есть; не хватает человека/мастера и гарантии (UNKNOWN) — открыто. ⚠️
- Премиальность на mobile? Да: воздух, крупные фото, антиква, sticky CTA. ✅

## 11. СРАВНЕНИЕ С КОНКУРЕНТАМИ

- Адаптировано: легенда материала (Riva 1920) → блоки «Материал» + featured-история; честные цены и ID (De La Espada/PINCH) → открытые цены и ID-паспорт; философия слэба (Nakashima) → editorial-подача объекта; макро как доказательство (топ-практики) → фото-система.
- Намеренно не использовано: marketplace-паттерны, «Furniture Tailoring»-терминология, аукционные механики (BDDW), журнальная перегрузка (Ligne Roset), выдуманные гарантии.
- Наш дифференциатор: тайга/Алтай как визуальный корень + верифицированный процесс + ID-паспорт каждого изделия + слэб как «объект», а не товар.
