DISCOVER → UNDERSTAND → ADMIRE → TRUST → EXPLORE → DESIRE → CONTACT.

## UX-принципы
- Ответ на каждый ключевой вопрос — без прокрутки «в никуда»: блоки ведут к следующему шагу.
- Два сценария: эмоциональный (главная → материал → изделие) и рациональный (каталог → категория → изделие); плюс прямой вход на карточку извне.
- Premium: фотография, воздух, тактильность; нет marketplace-шума, бейджей, фальшивых отзывов.
- Мобильная версия — отдельная логика: sticky CTA, swipe-галерея, сокращённые breadcrumbs.
- UNKNOWN-поля не блокируют публикацию, но не заполняются выдумкой.

## Требования к заявке
- Форма заявки доступна с любой страницы за ≤ 2 клика (SUCCESS CRITERIA).
- На карточке изделия форма предзаполняется ID изделия.
