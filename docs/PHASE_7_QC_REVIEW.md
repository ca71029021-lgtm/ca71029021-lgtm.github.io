## 4. Доступность (a11y) — PASSED WITH NOTES

| Проверка | Результат |
|---|---|
| `lang="ru"` | есть |
| Контраст основного текста | #211C15 на #F7F4EE = 15.41:1 — отлично |
| Белый текст на фото-секциях (.atmo, .tile) | лежит поверх фото + скрим rgba(28,35,32,0.45) — читаемо |

Замечания (не блокирующие, кандидаты в refinement перед production):

- **A1.** Акцентные ссылки #8F6A3F на #F7F4EE = 4.45:1 — на 0.05 ниже порога WCAG AA 4.5:1 для мелкого текста. Косметически незаметно, но для strict AA можно чуть затемнить акцент.
- **A2.** Кнопки фильтров каталога не выставляют `aria-pressed` — скринридер не объявляет активный фильтр (визуальный класс `on` есть).
- **A3.** Бургер-меню: у кнопки нет `aria-expanded`, у `#mmenu` не управляется `aria-hidden`.
- **A4.** Форма заявки: `<label>` не связаны с полями (нет `for`/`id`), у полей нет `name`, нет `required`/валидации. Для прототипа допустимо, перед production — обязательно.
- **A5.** Устойчивость: белый текст поверх фото-секций станет невидимым, если фоновое фото не загрузится (нет тёмного fallback-фона у `.atmo`/`.tile`).
