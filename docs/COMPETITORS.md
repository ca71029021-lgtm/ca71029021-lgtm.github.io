## Главные выводы для PHASE 3
1. MUST HAVE: легенда кедра Алтая, мастер за изделием, статусы, гарантия, макро фактуры, двухуровневый CTA (Discover + Consultation), верификация цифр.
2. Ценовая модель CTA для эксклюзивной handmade-мебели — консультация/custom order, не «купить в 1 клик» (окончательный CTA решает владелец в PHASE 3).
3. Наши сильные стороны (hero с тайгой, палитра, процесс, bespoke-оффер) — сохранить; слабые (нет человека, нет гарантии/соцдоказательств, непроверенные цифры, пустые карточки) — закрыть.
4. DO NOT COPY: чужие слоганы, композиции, термины (Furniture Tailoring), изображения — INSPIRED BY, не COPY.
