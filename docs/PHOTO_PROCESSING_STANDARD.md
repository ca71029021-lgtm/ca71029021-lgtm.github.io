## 1. ГЛАВНЫЙ ПРИНЦИП

Достоверность изделия абсолютна. Не меняются: форма, геометрия, пропорции, толщина деталей, конструкция, цвет древесины, естественная текстура, сучки, трещины, природные особенности, металл, фурнитура, признаки ручной работы. Нельзя «улучшать» изделие так, чтобы оно выглядело иначе, чем в реальности.

## 2. ПАРАМЕТРЫ ЭТАЛОНА (предложение — ОТКЛОНЕНО владельцем, не применяется)

| Параметр | Значение |
|---|---|
| Фон | Тёплая студийная плавка (не чисто белый): верх `#F2EDE4` → низ `#E6E0D5`, лёгкий радиальный свет (без виньетки-затемнения) |
| Яркость фона | Средняя яркость (L) ≈ 230 |
| Баланс белого | По стене (светлые нейтральные пиксели верхней трети кадра), едва тёплый сдвиг (R ×1.006, B ×0.994) — без оранжевого сдвига кедра |
| Контраст | Мягкая S-кривая, коэффициент ±0.09, clipping отсутствует |
| Тени | Естественная контактная тень сохраняется; «парящих» изделий, glow, виньеток нет |
| Кадр каталога | 4:5, изделие занимает ~72% высоты кадра, центрирование по объекту, важные части не обрезаются |
| Перспектива | Не корректируется агрессивно; допускается только лёгкая профессиональная коррекция |
| Резкость | Микро-резкость (UnsharpMask radius 1.2, amount 38, threshold 3) — без эффекта «oversharpen» |
| Формат экспорта | JPG quality 88, 1200×1500 (каталог) |

## 3. КЛАССИФИКАЦИЯ ФОТОГРАФИЙ

- **A — PRIMARY PRODUCT PHOTOS** (главные кадры каталога/карточек): к ним применяется полный стандарт (фон + цвет + кадр).
- **B — SECONDARY** (вторые ракурсы галереи): тот же стандарт фона.
- **C — INTERIOR / LIFESTYLE**, **D — WORKSHOP / CRAFTSMANSHIP**: к единому фону НЕ приводятся (в проекте отсутствуют — PHOTO TO PRODUCE).
- **E — DETAIL / MACRO**: только цветокоррекция, фон не меняется.
- **F — PHOTO TO REPLACE**: фото ниже качества спасения — в список пересъёмки.

## 4. ДВУХУРОВНЕВЫЙ ПОДХОД (ключевое решение предложения)

По результатам тестов автоматической сегментации:

- **Категория A1 — съёмки на текстильном/студийном фоне без пола** (серии `retuch`: S001–S007, SN017–SN026, SNS030–SNS032): унификация фона **выполнима автоматически сейчас**, качество — по образцам ниже.
- **Категория A2 — кадры с полом/интерьером** (серии `_0xx`: SN008–SN016; SNS027–SNS029, SNS033): автоматическая сегментация пола **ненадёжна** (риск затронуть изделие). Варианты: (a) поштучная AI-ретушь фона с ручной проверкой каждого кадра (AI — только на удаление фона, по регламенту §10 файла владельца); (b) оставить оригинал с цветокоррекцией и статусом **PHOTO TO REPLACE** до студийной пересъёмки. **Рекомендация — (b)**: владелец планирует студийную пересъёмку для финальных фото, прототипные кадры временные.

## 6. AI / RETOUCH LIMITATIONS (зафиксированы)

AI допускается только для: аккуратного удаления/замены фона; удаления мелких загрязнений фона; выравнивания света; цветокоррекции; аккуратного кадрирования. AI не дорисовывает изделие, не меняет конструкцию/текстуру/цвет материала, не удаляет природные дефекты древесины, не создаёт новые элементы, не меняет металл, не создаёт интерьеры. **Решение владельца (2026-10-26): замена фона / AI-обработка в проекте НЕ используются вообще — только допустимая техническая подготовка (см. шапку).**

## 7. СПИСОК PHOTO TO REPLACE / ПЕРЕСЪЁМКА

1. **SNS028** — критично: нет пригодного студийного кадра вообще (PHOTO AUDIT §5). Пересъёмка обязательна.
2. **SN010** — один общий план; ракурс для галереи один.
3. **SN011** — качество среднее.
4. **Категория A2 целиком** (SN008–SN016, SNS027–SNS029, SNS033): если нужен единый фон до студийной пересъёмки владельца — только поштучная AI-ретушь с ручным QC; иначе статус PHOTO TO REPLACE.
5. SNS029 — жёлтый каст (лечится цветокоррекцией, без пересъёмки).
6. PHOTO TO PRODUCE (без изменений): мастерская, процесс, интерьеры, портрет.

## 8. РЕШЕНИЯ, КОТОРЫЕ НУЖНЫ ОТ ВЛАДЕЛЬЦА

1. Утвердить / скорректировать параметры эталона (§2) после просмотра 4 примеров.
2. Выбрать путь для категории A2: AI-ретушь поштучно или PHOTO TO REPLACE до студийной пересъёмки.
3. После утверждения — разрешение на массовую обработку PRIMARY PRODUCT PHOTOS (категория A1) по эталону.
4. Тайминг студийной пересъёмки (SNS028 + финальные фото).
